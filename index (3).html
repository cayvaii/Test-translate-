1. เลือกภาพ

หมายเหตุ: เว็บไซต์ต้นทางอาจบล็อกการโหลดรูปข้ามโดเมน (CORS) หากโหลดไม่ได้ ให้ดาวน์โหลดรูปจากเว็บไซต์นั้นแล้วอัปโหลดไฟล์แทน

2. ตั้งค่าการแปล

บริการแปลภาษาภายนอกอาจต้องใช้ API key หรืออาจมีข้อจำกัดการใช้งาน คุณเปลี่ยน URL ของเซิร์ฟเวอร์แปลภาษาที่คุณมีสิทธิ์ใช้งานได้

เลือกภาพเพื่อเริ่มต้น

3. ตรวจทานข้อความ

การสร้างภาพจะปิดทับบริเวณข้อความโดยประมาณและวางคำแปลแทน ไม่ใช่การลบข้อความด้วย AI; ภาพที่มีพื้นหลังซับซ้อนอาจมีรอย
